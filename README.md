# gmail-organizer

Gmail のラベル振り分けを Google スプレッドシートで一元管理し、Google Apps Script で
自動適用・ログ記録し、週次で AI が改善提案を出す仕組み。

受信トレイ 11,642 通 / 未読 9,225 通、ユーザー定義ラベル 39 個 という状態からの出発点です
(2026-08-19 時点)。
